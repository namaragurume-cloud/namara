# NAMARA REVIEW サービス仕様

## 概要

| 項目 | 内容 |
| --- | --- |
| サービス名 | NAMARA REVIEW |
| 運営 | なまらグルメ |
| 対象 | 個人経営の飲食店、複数店舗を運営する飲食企業（居酒屋・焼肉・カフェ・レストランなど） |
| コンセプト | 口コミ管理は、AIにおまかせ。お店はお客様に集中できる。 |

Google口コミの取得・管理・AI返信・分析を一元化し、店舗オーナーがLINEから簡単に対応できるようにする。
忙しいオーナーが**管理画面を毎日開かなくても使える**ことを最優先にする。

### 差別化

1. LINEを中心とした簡単な操作
2. 店舗の特徴に合わせた自然なAI返信
3. 口コミから経営改善につながる分析
4. 複数店舗の一元管理
5. ITが苦手な飲食店でも使いやすいUI

## 利用者と権限

| 利用者 | 権限 | できること |
| --- | --- | --- |
| オーナー | owner | 全店舗の閲覧・返信の承認と投稿・設定・担当者の招待と権限変更・契約の確認 |
| 店長 | manager | 担当店舗の閲覧・返信の承認と投稿・店舗設定・通知設定 |
| スタッフ | staff | 担当店舗の閲覧・返信案の作成と編集・承認依頼（投稿はできない） |
| 運営（なまらグルメ） | 運営専用権限 | 契約店舗一覧・利用状況・連携エラー・売上・サポート対応（店舗ユーザーとは完全に別の権限） |

- オーナー権限は招待では付与しない（権限昇格防止。変更は運営経由）。
- 担当店舗以外のデータは表示も操作もできない。

## 中心となる流れ（返信）

1. Googleに新しい口コミが投稿される
2. NAMARA REVIEW が口コミを取得する（定期同期）
3. AIが返信案を作成する
4. 担当者のLINEへ通知する
5. 担当者が返信内容を確認する
6. 必要に応じて編集する（トーン変更・再生成も可能）
7. オーナー・店長が承認する（スタッフは承認依頼まで）
8. Googleに返信を投稿する
9. 投稿結果をLINEとダッシュボードに反映する

返信のステータス：`未返信 → 下書き → 承認待ち → 投稿中 → 返信済み / 投稿失敗`

- **AIによる無断の自動投稿は行わない。**
- 承認待ちの返信案を編集すると、承認依頼はやり直しになる（承認した内容と投稿内容のズレを防ぐ）。
- 投稿は冪等キー（口コミID＋返信案の版数）で管理し、二重投稿しない。失敗した投稿は再試行できる。

## AI返信のルール

- 丁寧な日本語。機械的な文章を避ける
- 口コミの具体的な内容（メニュー名など）に触れる
- 店舗の文体（トーン：丁寧／親しみやすい／カジュアル）と署名に合わせる
- 高評価は感謝中心、低評価はお詫び＋ご意見の受け止め
- 口コミにない事実を追加しない
- 返金・無料・割引などの補償や、断定的な改善を約束しない
- 投稿者の名前など個人情報を不必要に使わない
- 店舗ごとに独自ルール・NGワード・低評価への追記文を設定できる

承認前に、自動チェック（NGワード・補償の約束・電話番号やメールアドレス・投稿者名・文字数）を表示する。NGワードを含む場合は承認できない。

## 画面

| 画面 | 主な内容 |
| --- | --- |
| ダッシュボード | 総口コミ数・平均星評価・今月の新規口コミ（前月同期比）・未返信件数・口コミ件数推移・平均評価推移・星評価分布・最新口コミ・AIからの改善提案・承認待ち／投稿失敗の通知 |
| 口コミ管理 | 一覧・星評価・投稿者・日時・本文・返信状況・星評価／返信状況フィルタ・店舗切替・キーワード検索・並び替え・返信案の作成／編集／承認 |
| AI返信管理 | 承認待ち・下書き・投稿履歴（失敗時の再試行）・返信ルール設定・未返信の返信案の一括作成・LINE通知の見え方 |
| AI分析レポート | 月別の件数と評価・前月比・ポジティブ／ネガティブの傾向・料理／接客／価格／雰囲気／提供時間／清潔感の分析・改善提案・店舗別比較・印刷（PDF保存） |
| 店舗設定 | 店舗情報・Google／LINE／AI連携状況・通知設定・AI返信方針とトーン・担当者と権限・契約プラン |
| 運営管理 | 契約店舗一覧・利用状況・プラン・Google連携状態・エラー件数・契約／解約状況・売上推移・サポート対応状況 |
| ログイン | メールアドレスとパスワード（Phase 2 で Supabase Auth） |

## MVPの完成基準

- スマホ・PCで快適に利用できる
- ログインができる
- 店舗ごとにデータが分離されている
- 口コミを一覧で確認できる
- Google口コミを取得できる
- AI返信案を生成・編集できる
- LINE通知を受け取れる
- 担当者の承認後にGoogleへ返信できる
- 評価推移を分析できる
- エラー処理がある
- セキュリティテストに合格する
