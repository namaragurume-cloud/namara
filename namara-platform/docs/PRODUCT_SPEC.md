# 製品仕様（PRODUCT_SPEC）

## 最重要コンセプト

> 北海道の人が探している飲食店の条件を把握し、その検索需要を店舗の集客・改善・商品開発に活用する。

- **なまらAI** は無料の便利な検索サービスとして成長させる（利用者を増やすことが最優先）。
- **NAMARA REVIEW** は、なまらAIの適法な匿名集計データと、Google口コミ・アンケートを使って、店舗に改善策と集客施策を提供する。
- なまらグルメの Instagram・PR制作・飲食店ネットワークは、NAMARA BOOST（PR相談）と店舗開拓で活かす。PR掲載は別契約で、SaaS加入による自動掲載保証はしない。

## 1. なまらAI（消費者向け・無料）

| 機能 | 仕様 | Phase 1 の状態 |
| --- | --- | --- |
| 自然文検索 | エリア・ジャンル・予算・利用シーン・人数・日時・個室/禁煙/子連れ等・その他キーワードを抽出 | ✅ 辞書＋ルール方式で実装（OpenAI 未使用） |
| 不足条件 | 質問を繰り返さず、分かる範囲で検索。エリア未指定なら全域から探した旨を表示 | ✅ |
| 推薦 | 実在店舗（本番）を最大5件。条件を満たさない店は出さない。5件未満ならその件数だけ | ✅（架空店舗） |
| 表示項目 | 店舗名・写真（許可/出典あるもののみ）・ジャンル・エリア・予算目安と根拠・合致理由・詳細/地図/予約リンク | ✅ 写真は未登録表示 |
| 不明表示 | 確認できない情報は「不明」 | ✅ |
| 広告 | 「広告（スポンサー）」表記の別枠1件 | ✅ |
| 言い換え提案 | 0件・少数時に「この条件を外すと N 件」を提示（勝手に緩めて表示しない） | ✅ |
| 保存 | お店の保存（イベント計測） | ✅ 計測のみ。保存一覧画面は未実装 |
| LINE | Webhook・署名検証・重複排除・Flex Message・レート制限 | ⚠️ コードとテストのみ。LINE 未接続 |

## 2. NAMARA REVIEW（飲食店向けSaaS）

| 機能 | 内容 | Phase 1 の状態 |
| --- | --- | --- |
| ダッシュボード | 総口コミ数・平均評価・月間新規・未返信・AI返信状況・表示回数・詳細閲覧・地図/予約クリック・地域需要・AI店長の提案 | ✅（口コミはモック、AI店長はルールベース） |
| NAMARA DEMAND | エリア/ジャンル/予算帯/シーン/希望条件別の検索数、自店の表示・クリック、少ない検索テーマ、前月比、集客機会分析 | ✅（合成データで表示） |
| Google口コミ管理 | OAuth・口コミ取得・フィルタ・未返信・AI返信案・編集・人の承認・投稿・履歴・二重投稿防止 | 🔲 DB設計のみ（Phase 8） |
| NAMARA VOICE | QRアンケート・満足度・項目別評価・自由記述・AI分類 | 🔲 DB設計のみ（Phase 9） |
| NAMARA ACTION | 今週の改善アクション3件・優先度・担当・期限・完了状況・前後比較・週次LINE | ⚠️ 提案3件の表示のみ。進捗管理は Phase 9 |
| NAMARA BOOST | SNS企画・リール台本・POP・季節キャンペーン・PR相談・成果測定 | 🔲 Phase 9 |
| スポンサー広告 | キャンペーン作成（審査申請）・対象・期間・予算・審査状況・表示/クリック/CTR/使用額・停止 | ✅ モック（決済なし） |

### 禁止事項（実装しない）
- 高評価の人だけを Google 口コミ投稿へ誘導する仕組み（レビューゲーティング）
- 口コミ投稿を条件とした特典・報酬
- 検索回数を来店数のように見せる表示

## 5. UI 方針
- 白基調＋ネイビー・ブルー。なまらAIは丸み・吹き出しで親しみやすく、NAMARA REVIEW はKPIカードと表で信頼感を重視。
- スマホ優先（なまらAI）、PC優先＋レスポンシブ（REVIEW・運営）。
- アニメーションは最小限（`prefers-reduced-motion` で無効化）。
- 空状態・データ不足・権限なしを分かりやすい日本語で表示。
