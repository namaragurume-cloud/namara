# 広告ポリシー（AD_POLICY）

## 1. 基本ルール
1. 検索結果の広告は **最大1件**。通常の推薦（最大5件）とは見た目も位置も分ける。
2. 広告枠には必ず **「広告（スポンサー）」** と表示し、「掲載料を受け取って表示している枠」と説明する（Web・LINE とも）。
3. **通常のおすすめ順位を広告費で変えない。** 広告の有無・予算額に関係なく通常順位は同じ（自動テストで確認）。
4. **検索条件に合わない広告は表示しない。**

## 2. 広告を表示する条件（すべて満たすとき）
- キャンペーンが運営の審査で「承認済み」
- 配信期間内
- 予算残高が1クリック分以上ある
- 店舗が公開・検証済み
- 検索にエリアかジャンルの指定がある（曖昧な検索には出さない）
- 指定されたエリア・ジャンルがキャンペーンの対象に含まれる
- 店舗が、その検索の **必須条件（予算・個室・ランチなど）をすべて満たす**
- 同じ店舗が通常の5件にすでに出ていない
- 複数候補がある場合：検索条件との一致度 → 予算消化率の低い順

## 3. 審査基準（運営）
- 店舗情報が運営の確認済みであること
- 誇大・虚偽表現、根拠のない「No.1」等がないこと
- 口コミ投稿を条件とした特典、高評価の依頼がないこと
- 対象エリアは店舗の所在エリアのみ（申請画面でも制限）
- 不適切な広告は運営がいつでも停止できる（監査ログに記録）

## 4. 課金（Phase 1 はモック・決済なし）
- 表示（`ad_impressions`）・クリック（`ad_clicks`）・課金（`ad_billing_events`）は別々に記録
- 仮の料金：1クリック40円、予算 9,800円〜
- 課金しないクリック（無効クリック）
  - 表示IDが存在しない／別セッションからのクリック
  - 表示から24時間を過ぎたクリック
  - 同じセッション・同じ広告への30分以内の再クリック
  - 1セッションで1時間に5回を超えたクリック
  - 予算残高不足（このとき配信を自動停止＝予算超過防止）
- IP 単位のレート制限（1分20回）も併用
- 課金イベントは1クリック1回まで（DB の UNIQUE 制約）

## 5. 今後
- 月額固定（9,800円/月〜）とクリック課金のどちらにするかは、オーナーと決定（現在はクリック課金で計算）
- 請求書発行・決済は Phase 10（決済サービスの選定と費用確認が必要）
- 景品表示法のステルスマーケティング規制に沿った表示であることを公開前に専門家確認
